# Границы и правила проекта

## Границы, решённые в спецификации
Один модуль — `index.html` (разметка + `<style>` + `<script>` в одном файле). Никто другой его не вызывает.

Разделы страницы, в этом порядке, с `id`:
- `#hero` — название (`<h1>`), описание, кнопка «Смотреть первую серию».
- `#characters` — заголовок «Герои», три карточки `.character`.
- `#trailer` — заголовок «Трейлер», блок 16:9 с кнопкой «▶».
- `#watch` — повтор кнопки «Смотреть первую серию» внизу.

Кнопки — элементы `<button type="button">` (не `<a>` без ссылки). Подсказка после нажатия — в элементе с `role="status"` рядом с кнопкой.

Заглушки — текст в виде `[… — впиши]`, обёрнутый в `<span class="placeholder">`.

## Швы для проверки
Проверка — открыть `index.html` в браузере (Playwright, Chromium) на ширине 1280 и 375 пикселей: все четыре раздела видны, нет горизонтальной прокрутки, нажатие на кнопки показывает подсказку, нет ни одного запроса во внешнюю сеть.

## Правила проекта
- Никаких внешних ресурсов (R08).
- Никаких выдуманных фактов о сериале — только заглушки (правило 3).

## Стек и команды
- Стек: чистый HTML + CSS + немного JavaScript в одном файле `index.html`. Ничего не устанавливается.
- Запуск: открыть `index.html` в браузере (двойной щелчок).
- **Команда проверки** (создаёт таск 01): `node tests/check.js` — открывает `index.html` в Chromium через Playwright (уже установлен в системе, `require('playwright')`, `chromium.launch()` без опций) на ширине 1280 и 375, проверяет критерии приёмки, печатает `N/M` и выходит с кодом 0 только если всё прошло. Отдельного запуска одного теста нет — файл один.
- Не трогать: всё вне `projects/landing/`; файлы `.autopilot/`, `AGENTS.md`, `CLAUDE.md`, `.gitignore`.

## Что построили таски
- **01:** разделы `#hero` `#characters` `#trailer` `#watch`; `.character` ×3 (`.portrait` + имя + фраза); `.trailer-box` (aspect-ratio 16/9); кнопки `button[type=button][data-hint]` (`.cta`, `.play`) с `role="status"` в своей секции; заглушки `span.placeholder` вида `[… — впиши]`. Проверка — `node tests/check.js` (28 пунктов).
