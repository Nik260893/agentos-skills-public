# Спецификация: Лендинг мини-сериала

## Задача
Автору мини-сериала нужна одна простая страница, которую можно показать зрителям: что за сериал, кто в нём, трейлер и кнопка, чтобы начать смотреть. Автор — новичок: открыть страницу должно быть просто, без установки чего-либо.

## Решение
- **R01** — одна страница в тёмном «киношном» стиле: тёмный фон, крупное название, яркая кнопка.
- **R03** — сверху, на первом экране — название сериала крупно (пока заглушка).
- **R02, R04** — под названием — короткое описание: 2–3 предложения о сюжете (пока заглушка).
- **R05** — блок «Герои»: три карточки, у каждой — место под портрет (цветной круг с инициалом-знаком вопроса), имя и одна фраза о герое (всё — заглушки).
- **R06** — блок «Трейлер»: прямоугольник 16:9 с кнопкой «▶» и подписью «Трейлер скоро». Ничего не грузит и никуда не ведёт.
- **R06.1** — по нажатию на «▶» под ним появляется надпись «Трейлер появится позже», чтобы нажатие не казалось поломкой.
- **R07** — кнопка «Смотреть первую серию» на первом экране. Ссылки нет — по нажатию ничего не открывается.
- **R07.1** — чтобы нажатие не казалось поломкой: страница не прыгает, рядом появляется подсказка «Первая серия скоро»; кнопка выглядит как кнопка (наведение, фокус с клавиатуры).
- **A01 → R07** — та же кнопка ещё раз внизу страницы, чтобы долистав до конца, не возвращаться наверх.
- **R14i** — страница читается на телефоне: карточки героев встают в столбик, ничего не вылезает за край экрана.
- **R12** — в конце сборки — простое объяснение в чате, как открыть страницу.
- **A02 → R12** — `README.md` в папке проекта с тем же объяснением и подсказкой, где менять заглушки, чтобы не искать его в переписке.
- **R09.1** — без JavaScript страница тоже показывает всё содержимое — подсказки к кнопкам просто не появятся.

## Решения по реализации
- **R09** — один файл `index.html`, стили внутри него (`<style>`), немного скрипта внутри (`<script>`). Почему: открывается двойным щелчком, нечего устанавливать и терять.
- **R08** — без ключей и паролей (их негде и незачем вводить), без оплаты (ничего не продаётся и не подключается), без внешних сервисов — никаких внешних подключений: ни шрифтов из интернета, ни картинок по ссылкам, ни счётчиков, ни видеоплееров. Шрифт — системный. Почему: так сказано в задаче, и страница работает без интернета.
- Все заглушки помечены одинаково — `[ … — впиши]` — и стоят видно, на самой странице. Почему: их легко найти поиском по `впиши`.
- Язык страницы — русский (`lang="ru"`), есть заголовок вкладки и `meta viewport`.
- **R10** — всё лежит в `projects/landing/`.
- **R11** — каждый шаг сохраняется коммитом и отправляется в ветку `claude/trusting-davinci-k1fnyl`.

## Как ведётся работа
- **Работа строго по скиллу Autopilot** (`skills/autopilot/SKILL.md`): все этапы и проверки по порядку.
- **R13** — всё общение с автором — простыми словами, без жаргона; технические слова, если без них никак, поясняются.
- **Вопросы — только там, где нужен выбор автора** (режим «полуавтомат»): брифинг уже прошёл, дальше вопросов не будет, кроме необратимых действий.
