# F1 — Свой текст вместо заглушки выглядит как обычный

**Требования:** A02, R02, R03, R05

## Что должно заработать

Автор делает всё, что написано в README, — и его настоящее название, описание и герои выглядят как обычный текст страницы, а не как жёлтая курсивная заглушка.

## Из брифа, дословно

> «Я новичок, объясняй простыми словами»
> Дополнение: «1 — заглушки»

## Разделы спецификации

«Решение» (A02), «Решения по реализации» (заглушки), «Открытые места».

## Критерии приёмки

- [ ] Craft · README.md:19 вместе с index.html:84,85,95-106 · условие: если автор сделает всё по README, его текст выглядит как обычный текст страницы, а не как заглушка (например, README прямо говорит убрать и обёртку `<span class="placeholder">…</span>`, либо разметка устроена так, что жёлтый курсив пропадает при замене текста)
- [ ] `node tests/check.js` проверяет это условие (после замены заглушки по README текст без стиля заглушки) и выходит с 0
