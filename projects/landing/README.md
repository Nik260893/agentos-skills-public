# Лендинг мини-сериала

Это одна простая страница о твоём сериале: название, описание, три героя, трейлер и кнопка «Смотреть первую серию». Вся страница — один файл `index.html`. Ничего устанавливать не нужно, интернет не нужен.

## Как открыть страницу

1. Открой папку `projects/landing/`.
2. Дважды щёлкни по файлу `index.html` (двойной щелчок мышью).
3. Страница откроется в твоём браузере.

Кнопки пока ничего не открывают — они только показывают подсказку («Первая серия скоро», «Трейлер появится позже»). Это нормально, ссылки появятся позже.

## Как заменить заглушки

Все тексты о сериале пока написаны жёлтым курсивом в квадратных скобках, например `[НАЗВАНИЕ СЕРИАЛА — впиши]`. Это заглушки: на их место нужно вписать свой текст.

1. Открой `index.html` в простом текстовом редакторе (Блокнот подойдёт).
2. Нажми Ctrl+F (на Mac — Cmd+F) и ищи слово `впиши`.
3. Найденную заглушку целиком, вместе с квадратными скобками, замени на свой текст. Остальное вокруг не трогай.
4. Сохрани файл и обнови страницу в браузере (клавиша F5).

Твой текст сразу будет выглядеть как обычный текст страницы — жёлтый курсив пропадёт сам. Жёлтыми останутся только те места, где ещё есть слово «впиши»: так видно, что осталось заполнить.

Что нужно вписать: название сериала (встречается и в заголовке вкладки), описание в 2–3 предложения, имя и одну фразу для каждого из трёх героев.

## Проверка (по желанию)

Если на компьютере есть Node.js и Playwright, из этой папки можно запустить `node tests/check.js` — он сам откроет страницу и проверит, что всё на месте.
